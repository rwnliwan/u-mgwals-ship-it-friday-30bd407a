Entry for the [Ship It Friday](https://make.fun/c/u-mgwals-ship-it-friday-30bd407a)
competition on make.fun: one line — the funniest git commit message an AI
coding agent writes in the moment before it breaks production on a Friday.

## The entry

> feat: flipped the new feature to 100% of users on Friday, the 1% test group loved it (all three of them)

104 characters. The agent's 1% test group loved the feature — all three of
them — so it rolled the feature out to everyone, on a Friday.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `$ENTRY_OUTPUT` or
`/output/entry.txt`:

```sh
node main.ts
```
